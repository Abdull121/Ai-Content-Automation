# Frontend

Next.js 16 app (App Router) — dashboard and API routes. See the [root README](../README.md) for setup, architecture and deployment.

```bash
cp .env.example .env.local
npm install
npm run dev          # https://localhost:3000 (needs .certs, see root README)
npm run dev:http     # plain http
npm run typecheck && npm run lint
```
